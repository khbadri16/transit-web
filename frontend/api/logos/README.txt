Shipping line logos for the folder cover (Documents page -> Folder cover)
========================================================================

Put one image per shipping line in this folder, named exactly like this:

    hmm.png          HMM
    cma-cgm.png      CMA CGM
    msc.png          MSC
    maersk.png       MAERSK
    akkon.png        AKKON
    white-line.png   WHITE LINE
    cosco.png        COSCO
    arkas.png        ARKAS

Any other line works too: the name in lower case, spaces become "-"
(e.g. "Turkon Line" -> turkon-line.png).

- PNG (best, transparent background), JPG or SVG.
- Any size; a wide logo is fine. It is fitted in the box automatically.
- No file = the line name is printed alone, in big letters.

After adding or changing a logo: push to GitHub (Vercel redeploys) —
the logo then appears on the website and on every cover.
